# Construction Site Record Book

Daily tracking app for construction site management.

## Features
- Attendance Register (Full day / Half day / Absent)
- Material Records (Morang, Gitti, Cement, TMT, Bricks)
- Trade Work (Wiring, Plumbing, Carpenter, Tiles, Painting)
- Daily Expenses
- Expenditure Summary
- Print Full Record Book
- Google Sheets Sync
- Custom Code Runner (Menu → Tools → Custom Code: paste AI-written JavaScript and run it inside the app; optional auto-run on startup)

## Access
Open `index.html` in any browser, or visit the GitHub Pages link.

## Tech
Single HTML file with JavaScript. No server needed. Data stored locally or synced to Google Sheets.
